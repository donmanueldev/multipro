# Multi PRO — identidad aprobada

Paquete de identidad para **Multi PRO**, una marca de variedad de productos pensada para resolver distintas necesidades bajo un mismo nombre.

- `svg/`: logos maestros y piezas vectoriales.
- `png/`: exportaciones listas para redes sociales y documentos.
- `fonts/`: Instrument Sans variable y licencia OFL 1.1.
- `docs/GUIA-DE-MARCA.md`: posicionamiento, paleta y reglas de uso.
- `docs/INVESTIGACION-TIPOGRAFICA.md`: decisión tipográfica documentada.
- `index.html`: manual visual y descargas.

El símbolo utiliza únicamente **verde**, **coral** y una **cuña violeta**. Negro y blanco se reservan para texto, fondos y variantes de contraste. No se permiten degradados, sombras, biseles ni fragmentos adicionales dentro del monograma.
